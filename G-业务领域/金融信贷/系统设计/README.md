金融信贷域 · 系统设计
====

> 本层回答：**单个系统的详细设计**（模块划分/接口契约/数据模型/关键时序/部署形态）。上承 [架构方案/](../架构方案/)（本系统在架构中的位置已定），下启 [模块设计/](../模块设计/)。

## 本篇目录

1. [授信系统设计](授信系统设计.md)——额度模型（总额 / 已用 / 冻结三分）、授信状态机、决策接口契约
2. [还款系统设计](还款系统设计.md)——还款方式矩阵、冲抵顺序、部分还款、逾期处理时序
3. [对账中心系统设计](对账中心系统设计.md)——渠道对账 / 内部对账 / 差错中心的模块划分与对碰算法
4. [决策引擎系统设计](决策引擎系统设计.md)——规则编排、特征接入、降级分级

## 与 C-架构/系统设计 的分工

[C 轨的系统设计](../../../C-架构/系统设计/)是**平台无关场景题**（秒杀/短链/Feed/限流——任何业务都适用的模式库）。本目录是**信贷业务耦合的系统设计**（离开信贷语境就不成立的设计）。写法规范一致（追问链 + 小结），互相引用场景模式而不复制。
