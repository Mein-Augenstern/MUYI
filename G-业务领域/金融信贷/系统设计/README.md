## 拟写篇目（按优先级）

| 篇目 | 覆盖 | 关联 |
|---|---|---|
| 授信系统设计 | 额度模型（总额/已用/冻结三分）/授信状态机/决策接口契约 | 业务知识/信贷业务全景 |
| 还款系统设计 | 还款方式矩阵/冲抵顺序/部分还款/逾期处理时序 | 业务知识/账务系统设计 |
| 对账中心系统设计 | 渠道对账/内部对账/差错中心的模块划分与对碰算法 | 业务知识/幂等与对账 |
| 决策引擎系统设计 | 规则编排/特征接入/降级分级 | 业务知识/风控决策架构 |

## 与 C-架构/系统设计 的分工

C 轨是**平台无关场景题**（秒杀/短链/Feed/限流——任何业务都适用的模式库）。本目录是**信贷业务耦合的系统设计**（离开信贷语境就不成立的设计）。写法规范一致（追问链+小结），互相引用场景模式而不复制。
