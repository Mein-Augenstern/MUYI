一、技术底子：成立即分布式
------

- 2014 年开业（国内首家民营银行，腾讯牵头），核心放弃 IOE 直接分布式，"全球首家全云上银行"[官方]
- 自研分布式核心 **Openhive"开放蜂巢"**（参数化/组件化/流程化/AI 原生），对外科技输出支撑出海 [官方/媒体]
- **DCN 单元化编年史** [技术社区]：

| 阶段 | 架构 |
|---|---|
| IDC 1.0（2014-16） | 两地三中心；同城主 SET 一主二备、异地两副本，DCN 级双活 |
| IDC 2.0（2016-18） | 同城三中心，单 SET 三副本跨中心，副本 6→3；RPO=0、RTO 秒级自动切换 |
| 2018-20 | 引入 TiDB 解中后台 3TB+ 容量瓶颈（存证/监控/反洗钱/历史明细） |
| 2020-24 | **TiDB 承载核心批量**：多 DCN 的 TDSQL 近实时同步汇总至 TiDB，联机批量解耦、微粒贷日终批量 3 小时 → 目标半小时 |

- 数据库：核心交易=腾讯 TDSQL（800+ 节点全行 OLTP）[媒体]；单账户年 IT 成本约 2 元（同业约 1/10）、单日峰值 14 亿笔 [媒体]
- **开源 38 项**（银行之最）：捐 Apache 两个（Linkis/EventMesh）、WeDataSphere 大数据套件（80 万行）、FISCO BCOS 区块链（600+ 产业案例）、FATE 联邦学习 [官方]

二、零售信贷条线：微粒贷 = 白名单邀请 + 联合贷
------

**与样本银行A 310 自营闭环的最大差异** [媒体]：
- 白名单邀请制（微信/QQ 流量入口，无主动申请入口）+ 小额分散 + 循环授信
- **联合贷**：样本银行B出风控与部分出资，数百家合作银行出资；早期市场惯例约 2:8，2021 年互联网贷款新规要求合作方出资 ≥30% 重塑结构
- 生态位反转（2025）：样本银行B成为多家银行合作白名单中的头部资产方/科技方——从募资方变为输出方

技术含义 [JD推断/技术社区]：信贷科技团队核心能力之一是**对外标准化的联合贷/银银对接**（出资分账/风控数据合规交互/监管要求的自主风控）；"贷款科技部门"主导核心批量优化。

其他条线：微车贷（场景嵌入，2015 起）[官方]；财富+（2022 一站式财富品牌）[官方]。

组织落点 [媒体]：个人金融事业群（16 部门，2024-25 架构改革后）——零售信贷部/汽车金融部/零售存款部/财富及养老金融部/零售风险部等。

三、对公条线：微业贷与企业数据风控
------

- **微业贷**（2017）：国内首个线上无抵押企业流贷；0 纸质资料、最高 1000 万、最快 1 分钟到账；30+ 数据源（工商/税务/征信/交易/物流）衍生数千参数 [官方]
- 科创贷（知识产权/人才资质数据授信）、微贸贷（贸易"单一窗口"四方联动）[官方/媒体]
- **战略权重转移**：企业贷款占比 2020 年 36% → 2024 年 49%，首次超过个人消费贷款——工程重心向企业数据风控/产业链场景倾斜 [媒体]
- 组织落点 [媒体]：企业及机构金融事业群（11 部门，含内嵌的"企金数字智能应用部"）

四、公共/中台：AI 原生银行与区块链
------

**AI 与数据智能（最鲜明标签）**：
- **杨强与 FATE**：2018 年任 CAIO（银行业唯一），提出联邦学习理论、2019 开源 FATE（全球首个工业级联邦学习框架）、IEEE 标准牵头；2026 退休转建行独董，CAIO 空缺 [媒体]
- **AI 原生银行（2025.3）三层体系** [官方/媒体]：基础设施（自研金融业首款 AI 智算交换机、算力 +3.5 倍、接入 DeepSeek-R1）/ 应用（70+ 数字员工、800+ 智能体，大模型日均调用 4.1 万→240 万次）/ 治理（AI 应用热力图 45 区块管理）
- 大模型路线=接入+工程化平台+联邦大模型研究（EMNLP 论文），**无自研开源大模型**（否定结论）[媒体]

**区块链与隐私计算**：分布式商业科技发展部（范瑞彬/张开翔）[媒体]；金链盟 + FISCO BCOS（国产首个金融联盟链底层）[官方]；WeDPR/WeIdentity/WeEvent 等 12 项开源 [官方]

**组织形态（与样本银行A的根本不同）** [媒体]：四大事业群制，科技归属**科技及智能事业群（13 部门）**，按业务域设"科技产品部落"（贷款科技产品部/存款科技产品部/政务和监管科技产品部）——业务-科技融合的产品部落制 vs 样本银行A的传统信息科技部条线制。

五、样本银行A vs 样本银行B：九维对照（行业双样本）
------

| 维度 | 样本银行B（B系生态） | 样本银行A（A系生态） |
|---|---|---|
| 数据基因 | 社交/流量 | 电商交易 |
| 核心数据库 | TDSQL + TiDB 批量卸载 | OceanBase 三地五中心 |
| 单元化 | DCN（客户号分片）+ Openhive | RZone/GZone/CZone + SOFAStack |
| 零售信贷 | 白名单邀请 + 联合贷（对外输出） | 310 自营闭环（码商/三农） |
| 对公小微 | 微业贷（政务税务数据） | 样本银行A贷（经营流水）+ 大雁图谱 |
| AI 路线 | 联邦学习起家 → AI 原生银行（800 智能体/智算交换机） | Agent First（百灵 2.0/八大工作台） |
| 开源 | 38 项 + 2 捐 Apache（最激进） | 相对保守 |
| 国际化 | 香港样本银行B科技（首家境外科技子行）→ 东南亚 5 家 | 跟随蚂蚁生态出海 |
| 组织形态 | 四大事业群 + 科技产品部落制 | 信息科技部条线制 |
