系统设计 · 场景题方法论
====

> 本目录定位：**平台无关的系统设计场景题**（秒杀/短链/Feed/限流——任何业务都适用的模式库）。
> 业务耦合的系统设计在 [G-业务领域/金融信贷/系统设计/](../../G-业务领域/金融信贷/系统设计/README.md)。这类设计离开业务语境就不成立，如授信系统/对账中心。两者通过互链挂钩而非复制。

## 方法论通则（四场景共用）

1. **先估算后设计**：QPS/存储/带宽的量级推导决定方案档次
2. **流量漏斗思维**：每层拦截多少、漏下去什么
3. **一致性取舍显性化**：强一致/最终一致/ tolerate 什么异常
4. **降级预案必答**：依赖挂了怎么办
