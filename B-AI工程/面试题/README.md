面试题 · 专题导读
====

本专题收录 2 篇，按主题独立检索；所在轨的导读页有本目录在全局中的位置说明。

## 本篇目录

1. [LLM应用面试题合集](LLM应用面试题合集.md)：基础篇，20 题（Q1–Q20）。八个主题：上下文工程、多轮会话状态、RAG、Agent 与工具设计、幻觉缓解、提示注入防护、成本控制、流式输出。例子来自 ai-service 的生产代码；
2. [智能体工程面试题-上下文与脚手架](智能体工程面试题-上下文与脚手架.md)：进阶篇，24 题（Q21–Q44）。六个主题：循环里的上下文、记忆、提示词缓存、脚手架、人机协同、评测与成本。例子来自 Claude Code、Anthropic、OpenAI 的公开资料。

## 答题的骨架

每题都是 30 秒版：先说结论，再讲机制，最后给一个自己项目的例子。遮住答案先说一遍，卡壳超过 5 秒的题，回读那道题后面链接的篇目。题库里没有的题，回到四条原则去推：窗口是预算，注意力有限；每一轮都在为全部上下文付费；模型的输出是概率性的；模型是不可信组件，边界画在工程层。

| 剩多少时间 | 读什么 | 怎么读 |
|---|---|---|
| 半天 | 基础篇 20 题；进阶篇挑 10 题（Q21–23、Q28–29、Q32–34、Q38、Q41）；[复刻清单](../脚手架设计/Agent脚手架复刻清单与面试追问.md)的十四问 | 只记每题的第一句结论。复刻清单的十四问对应"怎么做才像 Claude Code 一样好用"，是这一个话题的完整连环追问 |
| 两天 | 第一天：[LLM 基础](../llm基础/LLM基础-Token上下文与幻觉.md)、[模型选型](../llm基础/2026-10模型生态与选型-没有全能冠军.md)、[系统提示词](../prompt/系统提示词工程-从财务诊断说起.md)、[Few-shot](../prompt/Few-shot与思维链.md)、[rag 四篇](../rag/)，配基础篇第一、二、三、五节；第二天：[agent 第一章](../agent/)、[上下文工程总览](../上下文工程/上下文工程总览-窗口里该放什么.md)、[四板斧](../上下文工程/Agent上下文工程-注意力预算与四板斧.md)、[提示词缓存](../上下文工程/提示词缓存-让重复的上下文变便宜.md)、[脚手架总览](../脚手架设计/Agent脚手架总览-ClaudeCode好用在模型之外.md)、复刻清单，配基础篇第四、六、七、八节和进阶篇 | 每读完一篇，合上书把文末的追问链自问自答一遍。第二天晚上用[自测清单](../../自测清单.md)的「AI 应用工程」一节过一遍，模糊和没学的做上记号 |
