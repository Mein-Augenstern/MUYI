# 协作与统计口径约定

> 2026-10-31 定稿（P0 治理批次）；2026-11-24 修订（B10 批次）：篇数改按正文计，数字与链接改由脚本把关，补充导航同步纪律。
> 本文解决三个反复出问题的口径：**README 统计数字怎么算**、**多会话/多人并行写库怎么不打架**、**导航页与在线书的顺序怎么保持一致**。所有规则都由脚本检查，不依赖人肉记忆。

## 一、统计口径（README 数据行与轨道表的唯一依据）

唯一来源是 `python3 scripts/stats.py`：在线书首页与站点描述在构建时直接读它生成的数字，README 里的数字由 `--check` 校验。

| 指标 | 定义 |
|---|---|
| 篇数（各轨/总数） | 轨道目录下的正文 md；不含 README.md / readme.md 这类导航页与配图说明 |
| 追问链 | 正文含「追问链」小节的篇数 |
| 自测题 | 自测清单.md 的表格数据行数（以 `\| 数字` 开头的行） |
| 配图 | git 跟踪的图片文件（png / jpg / jpeg / gif / webp，不含 book/） |
| 目录导读 | 轨道目录下名为 README.md 的导航页数 |

复算：`python3 scripts/stats.py`。校验 README：`python3 scripts/stats.py --check`（不一致退出码 1；发布前与每周体检都会跑）。

**篇数口径变更（2026-11-24）**：10-31 至 11-23 的约定是「含轨道 README 与 picture 说明 readme」，实算 482；但根 README 轨道表用的是一套对不上任何口径的旧数（加总 394），在线书首页又写 479——同一个词三种数。11-24 起统一为只数正文（396）：「篇实文」对读者就是文章，导航页不算。更早的历史：2026-10-31 前数据行曾用人工策展数（347），与脚本口径出现 47 篇偏差，自 10-31 起统一为脚本口径。

**更新纪律**：增删文章、题目、图片后同步 README；漏了会被 `--check` 拦住，不会悄悄上线。

## 二、链接与导航

1. **链接目标里的空格写成 `%20`**。`[x](a b.md)` 按 Markdown 标准不是链接，在 GitHub 和在线书上都会显示成字面文本。
2. **路径大小写必须与文件名一致**。macOS 不区分大小写，写错了本地照样能打开，到 GitHub 和线上是 404。
3. **每篇正文必须被本轨至少一个 README.md 链接**——读者从导航页要能点到它。
4. **README 的目录顺序就是在线书里侧边栏与「上一篇 / 下一篇」的顺序**。想让某篇排在前面，就把它在 README 的目录里往前放；README 没提到的条目排在后面（先子目录后文章，各按标题序）。
5. **目录链接、README.md 链接可以放心用**。构建时自动处理：目录有导读页则保留可点，没有则降为纯文本；`xxx/README.md` 改写成目录地址。
6. **「写作规范」段只给维护者看**。README 里以「写作规范 / 写作约定 / 写作纪律」为题的段落，在 GitHub 上可见，在线书里构建时自动去掉。

第 1–3 条由 `python3 scripts/check_links.py --src` 检查（区分大小写，能识别裸空格链接）；构建产物里的死链、死图由 `python3 scripts/check_links.py --dist book/dist` 检查。

## 三、多会话并行写库纪律（防裹挟与覆盖）

背景：多 Agent 会话并行建设本库（曾发生 `git add -A` 把另一会话未提交改动裹挟进提交的事故）。

1. **提交用显式文件名**：`git add <path1> <path2>`，禁止 `git add -A / git add .`；
2. **写前探测**：动手前 `git status --short` 看是否有他人未提交改动，有则只动自己的文件并在回报中说明；
3. **不改别人口径**：README 统计行只按第一节规则整体更新，不混入私人口径；
4. **推送失败降级**：github.com 主站阻断时走 git data API 通道（constellation/skills/github-cn），远端 tip 实时获取不依赖本地指针；
5. **批次台账**：跨文件治理动作（改名/去重/迁移）一律落 `docs/治理/台账-B*.md`，先记后做或同步记录。

## 四、引用规范

见根 README「引用与诚信规范」条目：研读重写 + 文末标注来源/版权；原文勘误或占位如实注明，不做虚假归属。先例：javadoop 系列 37 篇（台账 B8）。
