## 维护规约

1. **实战反哺**：star-site / voice-zcode 每落地一个技术组件，当天回写一篇到对应主题。
2. **提交纪律**：一篇一 commit，格式 `新增: <主题>/<篇名>` 或 `更新: <主题>/<篇名> — <改了什么>`。
3. **季度自测**：每季度末过一遍[自测清单](自测清单.md)的 P0 部分，标记掌握度。
4. **年度体检**：每年 10 月重跑覆盖盘点，定来年补全重点。
