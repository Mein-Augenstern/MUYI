## 这本库是什么，不是什么

| 它是 | 它不是 |
|---|---|
| 一个**按工程项目治理**的知识库：体检脚本持续验证零空壳零死链，配图全部本地化自包含 | 链接收藏夹或转载集合——早期整理篇目均标注来源，2026 起以原创生产实践为主 |
| **上线后的复盘笔记**：文章从真实生产代码回写，引用真实类名与文件路径，可点击验证 | 背诵型面试题库——每篇深度文带「追问链 + 面试官视角小结」，答案要经得起连环追问 |
| 一个**持续生长的体系**：一篇一 commit，组件落地当天回写，季度自测、年度体检 | 一次性冲刺的产物——2018 年首篇至今 8 年，commit 记录就是活性证明 |
| **电子书 + 仓库双形态**：VitePress 编译、push 即重建，与仓库同源零复制 | 只有代码没有内容的工程模板 |

## ✨ 三个不可复制点

### 1. 生产反哺：文章从上线的代码里长出来

2026 年起，知识库的写入路径变更为「组件落地当天 → 回写复盘」。每篇引用**真实类名与文件路径**——不是示意代码，是可以在生产仓库里指出对应文件的实录。抽样八篇：

- 🔥 [分布式 ID：从雪花算法到生产实现](C-架构/分布式系统/分布式ID/分布式ID-从雪花算法到生产实现.md) —— `__global__` 池 + `LAST_INSERT_ID` 原子租约、时钟回拨钳制、Hikari 连接风暴下的分配等待。含一次源码审计发现的真实边界
- 🔥 [支付回调的 HMAC 验签与幂等设计](A-后端内核/框架与中间件/安全/支付回调的HMAC验签与幂等设计.md) —— CAS 状态机五层幂等语义、时序安全比较。走读 mock/微信/支付宝三渠道真实代码
- 🔥 [ReAct 与 LangGraph 工程实践](B-AI工程/agent/ReAct与LangGraph工程实践.md) —— 智能体身份链"模型无法伪造"设计、SSE 流式事件分类、MemorySaver 记忆隔离（来自 Python LangChain 服务）
- 🔥 [信贷业务全景与领域模型](G-业务领域/金融信贷/业务知识/信贷业务全景与领域模型.md) —— "一条贷款从生到死"全程走通，限界上下文切分。额度账户与借据状态机两个最易做错的模型
- 🔥 [幂等与对账：资金安全底座](G-业务领域/金融信贷/业务知识/幂等与对账-资金安全底座.md) —— 资金链路每一步的幂等语义分级。对账差错的自动定位与人工兜底边界
- 🔥 [观测性三件套：Metrics / Logging / Tracing](C-架构/DDD与方法论/方法论/观测性三件套.md) —— 三支柱的信号分工与联动排障路径，落到真实告警配置
- 🔥 [从 Java 视角看 Python/TypeScript 工程化](A-后端内核/python/从Java视角看Python工程化-开篇.md) —— 全栈迁移的对照式学习法：Java 概念 → Python/TS 差异 → 生产项目落点
- 🔥 [K8s 生产排障手册](D-云原生/容器技术/Kubernetes/K8s生产排障手册.md) —— 滚动更新丢流量、探针误杀、preStop 与终止 grace 的手序问题，均来自真实事故复盘

### 2. 深度有统一标尺：源码级追问链

每篇深度文标配「追问链 + 面试官视角小结」。标准不是"能答上来"，是**经得起连环追问**：答案的每一层都预埋了下一层的入口。面试官往哪挖，哪里就有准备。全库按 [113 题自测清单](自测清单.md) 索引，每题挂答案定位与掌握度标记，季度复查。

### 3. 整库按工程项目治理

- **零空壳零死链**：[kb-upkeep 巡检 skill](https://github.com/Mein-Augenstern/constellation) 定期体检（空壳 0 / 占位 0 / 死链 0 / 死图 0）
- **290 张配图全部本地化**：不依赖任何外站图床，克隆即可完整阅读
- **内容治理流程化**：2026-10 起按轨道分批精修（合并碎片/删除冗余/电子书化命名）。全程一篇一 commit、台账留痕（[治理台账](docs/治理/)）
- **敏感词断言**：电子书构建管线内置检查，涉密内容无法进入公开产物
