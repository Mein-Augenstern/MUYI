GMV（Gross Merchandise Volume，商品交易总额）
====

一句话描述
====

GMV 即商品交易总额：只要用户**拍下/提交了订单**，订单金额就计入 GMV。不管后续是否付款、取消、拒收、退货。它是电商平台衡量**流水规模**的基础业务指标。和 [PV](PV.md) 一样属于"业务有多火"的世界。与 [QPS](QPS.md) 这类"系统扛不扛得住"的技术指标分属两个口径。

看在前面
------

* <a href="https://www.zhihu.com/question/20146641">电子商务里面的 GMV (Gross Merchandise Volume) 的定义是什么？和销售额的区别是什么？</a>

第一种说法
------

GMV=1销售额+2取消订单金额+3拒收订单金额+4退货订单金额。GMV是流水，只要你下了订单，生成订单号，就算了GMV。而这个订单转化为平台的实际收入还会有2、3、4这些流失量。

下单以后后悔了取消订单，订单送到你面前了后悔了拒收订单。签收订单以后后悔了要退货。这个步骤不同的电商平台计算方法不一样（有的平台是不管退不退货都搜算进销售额中）。所以当我们看到各大电商平台公布的GMV数据都是有很大的水分的，上市公司除外。上市公司公布的GMV会有详细的指标释义，我公式中列举的GMV是最具水分的一种算法。

第二种说法
------

GMV (Gross Merchandise Volume) 一般只有平台类的电商网站才喜欢这么说法，比如淘宝、TMALL。在电商网站定义里面是网站成交金额，这个实际指的是拍下订单金额，包含付款和未付款的部分。而销售额一般对应的是b2c自营网站，那个就是实际流水了。

以前一些活动销售额的新闻报道，网站喜欢给的是GMV金额。无他，数字大，好看。实际付款金额要略低一些，因为有时候是隔天付款，但是订单成交是在当天。当然，实际订单可能不支付，所以GMV肯定大于实际销售额。所以这个是经常出现在报道和新闻里面的。

一、口径拆解：哪些算、哪些不算
------

GMV 的数字之争本质是口径之争，同一个"双十一 GMV"，每家计入的环节并不相同：

| 环节 | 是否计入 GMV | 说明 |
| ---- | ---- | ---- |
| 拍下未支付 | 大多数平台计入 | "生成订单号即计入"，是 GMV 大于销售额的主因 |
| 取消订单 | 高水分口径计入 / 严格口径剔除 | 上市公司披露时会附指标释义 |
| 拒收、退货 | 同上，各家不同 | 有的平台无论是否退货都先算销售额 |
| 运费、优惠券、补贴 | 各家不同 | 有按商品总额的，也有按实付金额的 |
| 刷单、异常订单 | 名义上剔除 | 实际是否剔干净，外部无法验证 |

速记：**口径从宽到窄：拍下 GMV > 支付 GMV > 确认收货 GMV > 销售额**。对比两家平台数字前，先问一句"你这个 GMV 拍下就算还是支付才算"。

二、GMV 与销售额的关系
------

* 公式（最宽口径）：`GMV = 销售额 + 取消 + 拒收 + 退货`，流失项即"GMV 的水分"；

* GMV 是**平台流水**视角（第三方商家的成交也算），销售额偏**自营收入**视角（B2C 自己卖货的实际流水）；

* 电商漏斗：曝光 → 点击 → 加购 → 下单（GMV 在这一层产生）→ 支付 → 签收 → 复购。GMV 高只说明漏斗前段宽，不代表钱真收到了。

三、GMV 与 QPS 的关系
------

GMV 与 QPS 没有直接换算公式，但容量规划时会沿这条链估算：

```
GMV（业务量） ÷ 客单价 = 订单数
订单数 × 集中系数 ÷ 集中时长 ≈ 下单峰值 QPS（技术量）
```

* 例：大促目标 GMV 100 亿、客单价 200 元 → 5000 万单。若 60% 订单集中在开卖前 10 分钟，则平均每秒约 5 万单。开卖瞬间脉冲还要再乘突发系数——订单创建接口、扣库存、支付回调都要按这个峰值设计；

* GMV 折算出来的是**下单峰值**。别忘了每次下单背后的连带流量：查商品详情、查库存、优惠券校验的 QPS 通常是下单本身的好几倍；

* 反过来，系统峰值 QPS 与转化率决定了"能承接多少 GMV"：下单接口扛不住，用户流失，GMV 自然上不去；

* 估算细节（集中系数、峰值/均值倍数）见 [QPS](QPS.md) 的 Little's Law 一节，PV→QPS 的折算思路见 [PV](PV.md)。

四、水分从哪来、怎么挤
------

* **口径水分**：拍下即计、含取消/退货、含运费补贴——同一家换口径可以"增长"不少；

* **刷单水分**：商家冲量刷单直接虚增 GMV，外部几乎无法识别；

* **挤水分的办法**：优先看**支付 GMV / 确认收货 GMV**。结合 [PV](PV.md)/UV、转化率、客单价交叉验证——流量没涨、转化率没涨、GMV 大涨，基本是口径或刷单问题。上市公司披露的 GMV 附带详细指标释义，可信度更高。

一句话总结：**GMV 数的是"订单流水"，不是"钱"；谈 GMV 先对口径，看 GMV 要挤水分。**
