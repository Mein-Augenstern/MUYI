JVM 推荐阅读
====

本目录（A-后端内核/java/JVM/）的微型阅读地图：先按主题找到入口文章，再顺藤摸瓜。（2026-10 由两条裸外链扩写为阅读地图，原外链保留在文末「外部资源」）

内存与对象
----

* [Java内存结构](JVM内存管理/Java内存结构.md)：运行时数据区（程序计数器、虚拟机栈、本地方法栈、堆、方法区、直接内存）逐区详解。含 JDK 8 前后方法区/元空间对比，是 JVM 内存主题的第一站。

* [垃圾收集算法](JVM内存管理/垃圾收集算法.md)：标记-清除、标记-复制、标记-整理三大算法与分代收集思想的原理讲解。

* [垃圾收集器](JVM内存管理/垃圾收集器.md)：Serial/ParNew/Parallel Scavenge/CMS/G1 各收集器的流程、优缺点、适用场景与参数总结，选收集器前必读。

* [查漏补缺](查漏补缺.md)：safepoint、JIT 分层编译、逃逸分析与标量替换、锁升级等高频但容易被漏掉的 JVM 问题。各自独立成节、随查随补。

性能兼容与故障处理
----

* [JVM性能兼容、故障处理](JVM性能兼容、故障处理/) 系列：最重要的 JVM 参数指南（含 GC 调优参数速查与调优策略）。另有 CMS 收集器参数详解、内存泄漏和内存溢出专题。以及高 CPU 占用、高内存占用、OutOfMemoryError、Linux 进程消失这类故障的诊断手册和 JVM 日志排查。

* [JVM故障排查FAQ](JVM性能兼容、故障处理/JVM故障排查FAQ.md)：按「停机或延迟过长 / load 高 / 进程挂了」等症状分类的排查入口清单，出问题先看这篇再深入对应专题。

外部资源
----

* R大知乎个人主页：https://www.zhihu.com/people/rednaxelafx —— HotSpot 虚拟机开发者。关于 JVM 内部实现、GC、编译器的第一手权威回答，深挖原理时优先检索他的回答与文章。

* https://github.com/fenixsoft —— 《深入理解 Java 虚拟机》作者周志明的 GitHub，含 jvm_book 样例代码与勘误仓库，配合该书阅读。
