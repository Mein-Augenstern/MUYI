# Spring 系列导读（书籍式目录）

> 按"IoC 与 Bean → AOP → Web 机制 → 事务与升级进阶"四层组织。源码分析（IOC 容器/AOP）是深度担当，升级要点（Boot3/Boot4）是时效担当。

## 目录

| 章 | 专题 | 回答的问题 |
|---|---|---|
| [01-IoC与Bean](01-IoC与Bean/) | 容器源码 / Bean 生命周期 / 循环依赖 / 依赖注入 | 对象从哪来、怎么装配、怎么解决依赖 |
| [02-AOP](02-AOP/) | 概念与指南 / 源码 / AspectJ | 横切关注点怎么织入 |
| [03-Web与常用机制](03-Web与常用机制/) | Servlet / 三器 / 异步 / 注解体系 | 请求进来发生了什么 |
| [04-事务与升级进阶](04-事务与升级进阶/) | 事务考点 / 设计模式 / Boot3·Boot4 升级 | 事务怎么生效、版本怎么跟 |

## 推荐阅读路径

* **源码深度路线**：01 的 IOC 容器源码 → Bean 生命周期 → 循环依赖 → 02 的 AOP 源码；
* **面试速通**：各章追问链 + [事务面试考点](04-事务与升级进阶/)。
